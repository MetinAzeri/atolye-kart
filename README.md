# Kilhane Atölye

El yapımı seramik ürünleri sergileyen çok sayfalı bir tanıtım/katalog sitesi — Ana Sayfa, Ürünler, Biz Kimiz ve Sepet sayfaları arasında gezinme içerir. Ürünler sepete eklenip adetleri düzenlenebilir; sepetteki siparişler "Siparişi Tamamla" adımında müşteri bilgileriyle birlikte webhook üzerinden iletilir.

🔗 Canlı site: https://metinazeri.github.io/atolye-kart/
