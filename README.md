# Kilhane Atölye

El yapımı seramik ürünleri sergileyen, tam bir e-ticaret deneyimi sunan çok sayfalı bir site — Ana Sayfa, Ürünler, Kendin Tasarla, Biz Kimiz ve Sepet sayfaları arasında gezinme içerir. Ürünler sepete eklenip adetleri düzenlenebilir; sepetteki siparişler "Siparişi Tamamla" adımında müşteri bilgileriyle birlikte webhook üzerinden iletilir.

**Kendin Tasarla**: kullanıcının ürün tipi (tabak/bardak/tepsi/vazo), sır rengi, desen ve isteğe bağlı bir yazı seçerek kendi özel seramik parçasını tasarlayabildiği, canlı SVG önizlemeli bir araç — tasarım tamamlanınca sabit fiyatla sepete ekleniyor.

🔗 Canlı site: https://metinazeri.github.io/atolye-kart/
